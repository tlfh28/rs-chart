# RS 차트 — 코스피·코스닥 상대강도

마크 미너비니가 쓰는 IBD식 RS 점수와 RS 라인을 코스피·코스닥 전 종목에 대해 계산해 보여주는 웹사이트.

- **RS 점수(1~99)**: 최근 3·6·9·12개월 수익률을 2:1:1:1로 가중 → 코스피+코스닥 전 종목 내 백분위
- **52주 신고가**: 당일 종가가 최근 52주(250거래일) 종가 중 최고인 종목 (상장 60거래일 미만 제외)
- 차트에는 RS 점수 70~100만 표시, 이동평균(50·150·200일)과 VCP 피벗 가격선
- **미너비니 스크리너**: 트렌드 템플릿 8개 조건 + VCP(최근 약 4개월 베이스의 고점→저점 하락폭이 2번 이상 연속 축소, 첫 수축 40% 이하·마지막 12% 이하, 베이스 3주 이상). 상태: 돌파(피벗 위 5% 이내 + 거래량 50일 평균 1.4배↑) / 피벗 근접(피벗 아래 6% 이내) / 수축 중

## 자동 갱신
`.github/workflows/update.yml` 이 평일 16:40(한국시간)에 실행되어 데이터를 새로 받고 사이트를 다시 배포한다.
수동 실행: 저장소 → Actions → "RS 데이터 갱신" → Run workflow.

## 파일
- `build_rs.py` — 데이터 수집(KIND·네이버 금융)과 RS 계산, 결과는 `docs/data/`
- `docs/` — 웹사이트 (검색·차트·순위표). 차트: TradingView Lightweight Charts
